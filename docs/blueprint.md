# **App Name**: DuetCast

## Core Features:

- Direct Messaging: Real-time text messaging between two users.
- File Sharing: Securely share files of various types between users.
- Audio/Video Calling: High-quality audio and video calls between users.
- Real-Time Music Sharing: One user can play a song, and the other user listens in real-time, synchronized.
- Video Streaming: Share local video files or stream live video, creating a shared 'TV' experience.
- Screen Sharing: Broadcast your screen to the other user for real-time collaboration or presentations.
- Content Moderation Tool: LLM detects whether the streamed audio or video contains any adult content, violence or misinformation, in which case the playing user gets a warning.

## Style Guidelines:

- Primary color: deep green, conveying trust and connection.
- Background color: Light blue-green providing a neutral, unobtrusive backdrop.
- Accent color: Energetic blue used to highlight interactive elements and calls to action.
- Font: 'PT Sans', a versatile, humanist sans-serif, used for both headlines and body text.
- Use clean, minimalist icons to represent actions and content types.
- Clean and intuitive layout, making navigation simple and user-friendly.
- Smooth, subtle transitions and animations to enhance the user experience without being distracting.
